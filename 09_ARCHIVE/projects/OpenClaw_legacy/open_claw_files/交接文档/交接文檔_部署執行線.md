## 如何在 Claude 工作時糾正它

### 常見失誤與糾正方式

**跑偏方向**：「停，我要的是 X，不是 Y。」不需要解釋理由。

**問題已解決還在繼續**（本次真實案例）：cron 工作流已成功推送，Claude 還在用 `openclaw agent` 指令測試連通性，得到 block 結果後繼續找解法。Jack 截圖「我已經收到消息了」才停。糾正：「問題已解決，停止當前操作。」

**工具掉線兜圈**：長對話末段工具必然掉線，不可恢復。直接說「開新窗口」。

**cron 配置後沒有主動驗證**：配置完要在下一個觸發時間後主動確認，不能配置完就算結束（本次失誤）。

**`openclaw agent` 指令不能驗證 cron 網絡**：兩種執行路徑不同，前者顯示 block 不代表 cron 也 block（本次誤判）。

### 實用原則
- 隨時說「停」，Claude 立即停止
- 不需要解釋理由，「不對，重來」就夠
- Claude 不記得上一個窗口的對話，每個新窗口必須讀交接文件

### 每日商業機會提案
- **Job ID**：2849eede-8368-48c3-a0fe-44037790595c
- **排程**：每日 08:50 Asia/Shanghai
- **當前狀態**：**已停止（enabled: false）**
- **流程**：researcher 四方向掃描 → data-analyst 評估 → ceo 產出 Top3 簡報 → Discord #ceo @Jack
- **重啟命令**：`openclaw cron enable 2849eede-8368-48c3-a0fe-44037790595c`
- **停止原因**：測試兩天（2026-03-19/20）功能正常，等所有角色 SOUL.md 優化完畢後重啟

### 問題一：Clash TUN + OpenClaw SSRF 衝突（已解決）
- **現象**：researcher 的 web_fetch 被封鎖，外部域名全部無法訪問
- **根本原因**：TUN 模式讓 DNS 解析返回虛擬 IP，SSRF 防護誤判為私有地址
- **解法**：openclaw.json env 加入 HTTP_PROXY=http://127.0.0.1:7897
- **注意**：HTTP_PROXY 對 cron isolated session 有效，對 `openclaw agent` 直接指令無效
- **注意**：TUN 模式必須保持開啟，否則 Discord 投遞被 403 拒絕
- **注意**：修改 openclaw.json 後必須 `openclaw gateway restart`

### 問題二：sub-agent 投遞超時（已理解，暫接受）
- **現象**：Discord 收到 CEO 的中間輸出（`capabilities=none`）而非最終格式簡報
- **原因**：Mac 安全更新重啟後 Gateway 啟動比 cron 觸發晚，sub-agent 投遞時 Gateway 未就緒
- **實際結果**：`lastDeliveryStatus: delivered`，簡報還是送到了
- **解法**：確保 Mac 在 08:50 前完全啟動，不需要調整 cron 時間

## 常用維運指令

```bash
# 狀態確認
openclaw gateway call health

# Cron 管理
openclaw cron list
openclaw cron enable 2849eede-8368-48c3-a0fe-44037790595c   # 重啟每日推送
openclaw cron disable 2849eede-8368-48c3-a0fe-44037790595c  # 停止每日推送
openclaw cron run 2849eede-8368-48c3-a0fe-44037790595c      # 手動觸發（必須用 ID）
openclaw cron runs --id 2849eede-8368-48c3-a0fe-44037790595c # 查看執行歷史

# Gateway 重啟（修改 openclaw.json 後必須執行）
openclaw gateway restart

# 日誌查看
tail -n 50 /tmp/openclaw/openclaw-$(date +%Y-%m-%d).log

# 過濾錯誤日誌
tail -n 100 /tmp/openclaw/openclaw-$(date +%Y-%m-%d).log | python3 -c "
import sys,json
for line in sys.stdin:
    line=line.strip()
    if not line: continue
    try:
        d=json.loads(line)
        level=d.get('_meta',{}).get('logLevelName','')
        if level in ('ERROR','WARN'):
            msg=' '.join(str(d.get(str(i),'')) for i in range(3) if d.get(str(i)))
            print(f\"{d.get('time','')}  {level}  {msg[:120]}\")
    except: pass
"

# 配置驗證
openclaw config validate
```

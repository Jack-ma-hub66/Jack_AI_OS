# OpenClaw 項目文件說明

## 目錄結構

| 目錄/文件 | 用途 |
|----------|------|
| `交接文档/` | 當前有效的交接文檔，新窗口開始時讀取 |
| `交接文档_歷史歸檔/` | 過期但保留的舊版交接文檔 |
| `backups_版本備份/` | SOUL.md 版本備份（版本驅動，非定時） |
| `prompt_skill_提示詞優化技能/` | Claude Project 的 Prompt Optimizer 技能文件 |

## 交接文檔說明

| 文件 | 說明 |
|------|------|
| `交接文檔_角色設計優化線_latest.md` | **角色設計線主文件**，新窗口第一個讀 |
| `交接文檔_角色設計優化線.md` | 角色設計線完整版（latest 是它的精簡更新版） |
| `交接文檔_部署執行線.md` | 部署和技術配置相關 |
| `完整交接文檔_系統全貌_20260320.md` | 系統全貌，從 Phase 0 到 Phase 3 完整記錄 |
| `頭腦風暴決策記錄_v1_20260319.md` | 架構設計期間的頭腦風暴和決策記錄 |

## 文件命名規則
- 每個文件名需有中文說明，看文件名就知道用途
- 重要決策寫入交接文檔，不依賴 Claude 記憶

## 備份策略
- 版本驅動備份（每次 SOUL.md 版本變更後備份）
- 路徑格式：`backups_版本備份/v{版本號}_{日期}/`
- GitHub 倉庫 `Jack-ma-hub66/openclaw-soul` 是主要版本控制
